Switching Workflow:
1. User adjusts parameters in Bank A (e.g., Mix = 40%, Output = +3dB)
2. User flips SW2 switch to Bank B position
3. System CAPTURES current Bank A parameters from APVTS → stores in bankA
4. System SWITCHES active bank pointer from A to B
5. System APPLIES Bank B parameters from bankB → writes to APVTS
6. Audio immediately reflects Bank B settings (e.g., Mix = 80%, Output = -6dB)
7. User toggles SW2 back and forth for instant A/B comparison
